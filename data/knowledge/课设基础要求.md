# Python 程序设计课设 — AI 方向基础要求（摘要）

## 基础必做（占总分 60%）

1. **GUI 图形界面**：使用 Tkinter 或 PyQt 等 Python 库，界面需适配 AI 应用场景，具备按钮响应、输入校验、加载状态提示，代码模块化。
2. **用户身份与权限管理**：本地账号密码存储，支持登录、注册、密码修改；至少区分普通用户与管理员两类权限。
3. **网络功能**：使用 requests/socket/urllib 等实现网络交互，如远程获取模型权重；需包含断网、下载失败等异常处理。
4. **数据库操作**：使用 SQLite 或 MySQL，设计用户表、AI 任务表等，实现完整 CRUD。
5. **AI 核心功能**：围绕选题实现核心 AI，优先使用成熟 Python 库；核心逻辑封装为独立模块（如 ai_core.py），与界面、数据库解耦。

## LLM 选题约束

- 禁止将公有云 LLM API 作为项目唯一核心能力。
- 云 API 可作为辅助（提示词生成、数据清洗、摘要、翻译等），核心业务须自主实现。
- 优先本地轻量 LLM（Transformers / llama.cpp）。
- 若硬件不足使用云 API 作核心推理，须额外实现至少两项：RAG 知识库、上下文管理、输出校验、可视化生成、权限管理等。

## 进阶选做（占总分 40%，选 1～3 项）

- 数据爬取与预处理（BeautifulSoup / Scrapy / Pandas）
- 结果可视化（Matplotlib / Seaborn / Plotly）
- 多任务并发（threading / multiprocessing / asyncio）
- 程序打包（PyInstaller / cx_Freeze）
- AI 模型轻量化优化与对比
- 日志与异常监控（logging 模块，支持查询导出）

## 验收

- 展示时间 8 分钟以内：PPT 讲解、功能演示、教师提问。
- 总分 50：基础功能 20、进阶 10、演示 5、报告 10、创新性 5。
